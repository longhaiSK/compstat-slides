Generating N(0,1) Random Variables

The Law of Large Numbers

Theorem 5.1.1 (Strong Law of Large Numbers) If random variables X_1, X_2, \ldots, iid from a distribution with finite mean \mu, then

P\left(\frac{X_1 + \ldots + X_n}{n} \to \mu\right) = 1 \tag{5.1}

This theorem says that if we can simulate X_i long enough, the sample average will almost surely converge to the true mean.

The Central Limit Theorem

Theorem 5.1.2 (Central Limit Theorem) If random variables X_1, X_2, \ldots, iid from a distribution with finite mean \mu and finite standard deviation \sigma, then

\frac{\bar X - \mu}{\sigma/\sqrt n} \to^d N(0,1) \tag{5.2}

CLT can be used to calculate error bound given a confidence level. For instance, given confidence level \alpha = 95\%, we can conclude from CLT:

P(-1.96\,\sigma/\sqrt n \le \bar X - \mu \le 1.96\,\sigma/\sqrt n) \approx 0.95 \tag{5.3}

Obviously, we see that the width of error bound will decrease with n, in a rate of square root.

-1.96 < \frac{\bar X - \mu}{\sigma/\sqrt n} < 1.96 \iff |\bar X - \mu| < 1.96\cdot\frac{\sigma}{\sqrt n}

\iff \bar X - 1.96\frac{\sigma}{\sqrt n} < \mu < \bar X + 1.96\frac{\sigma}{\sqrt n}

A Toy Example: Estimating \pi with Monte Carlo Method

Suppose random variables X, Y are uniformly distributed over rectangle S = (-1,1)\times(-1,1), as displayed in Figure 5.2. The probability that (X,Y) lies in the ball C = \{(x,y)\mid x^2+y^2 \le 1\} is \pi/4, in other words,

E(4\times I((X,Y)\in C)) = \pi.

We can draw samples of (X,Y) uniformly from S and count how much proportion of these samples fall into C, then \pi is estimated by:

\hat\pi_n = 4\times \frac{\sum_{i=1}^n I((X_i,Y_i)\in C)}{n} \tag{5.4}

Figure 5.2: Estimating \pi

(X,Y)\sim \mathrm{Unif}(S)

The probability that (X,Y) lies in the ball C=\{(x,y)\mid x^2+y^2\le 1\} is \pi/4

P((X,Y)\in C) = \frac{\pi}{4}

E(I((X,Y)\in C)) = \frac{\pi}{4}

I((X,Y)\in C) = \begin{cases} 1, & (X,Y)\in C \\ 0, & \text{o.w.} \end{cases}

Z = 4\cdot I((X,Y)\in C), \quad E(Z) = \pi

Z_1, Z_2, \ldots, Z_n \;\Rightarrow\; \bar Z = \frac{Z_1+\cdots+Z_n}{n} = \hat\pi

Evaluation of Point Estimators

\hat\theta^{(1)} = \hat\theta\big(X_1^{(1)}, \ldots, X_n^{(1)}\big)

\hat\theta^{(2)} = \hat\theta\big(X_1^{(2)}, \ldots, X_n^{(2)}\big)

\vdots

\hat\theta^{(N)} = \hat\theta\big(X_1^{(N)}, \ldots, X_n^{(N)}\big)

We evaluate a point estimator \hat\theta by its Mean Squared Error:

\mathrm{MSE} = E\big((\hat\theta - \theta)^2\big)

Estimated by Monte Carlo with N repetitions:

\widehat{\mathrm{MSE}} = \frac{\sum_{i=1}^N (\hat\theta^{(i)} - \theta)^2}{N}

Uniformity of pv(T) under H_0

pv(T) \mid H_0 \sim \mathrm{Unif}((0,1))

Pf:

pv(T) = 1 - F_{H_0}(T), where F_{H_0} is the CDF of T\mid H_0.

Under H_0:

F_{pv(T)}(t) = P(pv(T) < t) = P(1 - F_{H_0}(T) < t)

= P(F_{H_0}(T) > 1-t)

= P\big(T > F_{H_0}^{-1}(1-t)\big)

= 1 - F_{H_0}\big(F_{H_0}^{-1}(1-t)\big) = 1-(1-t)

= t
