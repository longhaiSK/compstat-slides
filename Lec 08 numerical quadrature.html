Numerical Quadrature

Numerical quadrature refers to numerically approximating a definite integral: A = \int_a^b f(x)\,dx, \qquad a, b \text{ finite}

Note that if a, b are not finite, we need to do a transformation first.

For example, let \theta = t(x) = \log\frac{x}{1-x} \quad \Longrightarrow \quad x = t^{-1}(\theta) = \frac{1}{1+e^{-\theta}}

If a=-\infty, b=+\infty, then \int_a^b f(x)\,dx = \int_{-\infty}^{\infty} f(x)\,dx = \int_0^1 f\!\left(t^{-1}(\theta)\right) dt^{-1}(\theta)

Example: Logistic Transformation

The logistic function maps the whole real line onto (0,1): y = \frac{1}{1+e^{-x}}, \qquad x = \log\left(\frac{y}{1-y}\right) = t(y)

Using this as a change of variables, \int_{-\infty}^{+\infty} f(x)\,dx = \int_0^1 f(t(y))\, t'(y)\, dy

Define g(y) = f(t(y))\, t'(y). The transformed integrand g(y) is now supported on the finite interval (0,1), so it is amenable to numerical quadrature.

Calculating a Probability

For the standard normal density \varphi(x) = \frac{1}{\sqrt{2\pi}}\, e^{-\frac{x^2}{2}} the probability that X falls in (a,b) is P(a < X < b) = \int_a^b \varphi(x)\,dx

Define the truncated density \varphi^{(t)}(x) = \varphi(x)\, I(a < x < b) so that this probability is the area under \varphi^{(t)}(x), shown shaded below.

Riemann Rule

Partition [a,b] into n equal sub-intervals of width h_n = \frac{b-a}{n}

The Riemann-sum approximation to the integral is \widetilde A_n = \sum_{i=0}^{n-1} h_n \cdot f(a + i\,h_n)

with \text{error} = O\!\left(\frac{1}{n}\right)

Midpoint Rule and Trapezoidal Rule

Midpoint Rule. With h_n = (b-a)/n, \widetilde A_n = \sum_{i=1}^{n} h_n \cdot f\!\left(a + \left(i - \tfrac12\right) h_n\right), \qquad \text{error} = O\!\left(\frac1n\right)

Trapezoidal Rule. With x_0 = a, x_1 = a + h_n, and h_n = (b-a)/n, on a single sub-interval \widetilde A_1 = \tfrac12\big(f(x_0) + f(x_1)\big)\cdot (x_1 - x_0)

Summing over all sub-intervals: \widetilde A_n = \tfrac12 h_n\Big[f(a) + f(a+h_n) + f(a+h_n) + \cdots + f(a+(n-1)h_n) + f(a+(n-1)h_n) + f(b)\Big] = \tfrac12 h_n\big[f(a) + f(b)\big] + h_n \sum_{i=1}^{n-1} f(a + i\,h_n)

Simpson’s Rule

Let n = 2m be even and h_n = (b-a)/n. On [x_0,x_1], approximate f by a quadratic \tilde f matching f at x_0, the midpoint, and x_1: \int_{x_0}^{x_1} f(x)\,dx \approx \frac{x_1-x_0}{6}\left[f(x_0) + 4\hat f\!\left(\frac{x_0+x_1}{2}\right) + f(x_1)\right] = (x_1-x_0)\left[\tfrac16 f(x_0) + \tfrac46 \hat f\!\left(\tfrac{x_0+x_1}{2}\right) + \tfrac16 f(x_1)\right]

Applying this on every pair of sub-intervals from a to b: \widehat A_{2m} = \frac{2h_n}{6}\Big[f(a) + 4f(a+h_n) + f(a+2h_n) + f(a+2h_n) + 4f(a+3h_n) + f(a+4h_n) + f(a+4h_n) + 4f(a+5h_n) + f(a+6h_n) + \cdots + f(b-2h_n) + 4f(b-h_n) + f(b)\Big]

= \frac{h_n}{3}\left[f(a) + f(b) + 4\sum_{i=1}^{m} f(a+(2i-1)h_n) + 2\sum_{i=1}^{m-1} f(a+2i\,h_n)\right]

An Example of Computing Marginalized Likelihood

We demonstrated the midpoint rule with a simple example.

Example (Normal data with log-norm prior for \sigma). The data X_1,\dots,X_n are modelled as IID samples from a normal distribution given the value of the mean parameter \mu and the logarithm of the standard deviation \sigma, denoted by w. The likelihood function of \mu and w based on data X_1,\dots,X_n is therefore: L(\mu,w) = \prod_{i=1}^n \phi(x_i;\mu,e^w) where \phi(x;\mu,\sigma) is the density function of a Normal distribution with mean \mu and standard deviation \sigma.

We assign normal priors to parameters \mu and w, with fixed \mu_0,\sigma_\mu,w_0,\sigma_w: \mu \sim N(\mu_0,\sigma_\mu), \qquad w \sim N(w_0,\sigma_w)

The density function of the prior for \mu and w is therefore: P(\mu,w) = \phi(\mu;\mu_0,\sigma_\mu)\,\phi(w;w_0,\sigma_w)

The posterior distribution of \mu and w can be found using Bayes’ rule: P(\mu,w \mid X_1,\dots,X_n) = \frac{L(\mu,w)\,P(\mu,w)}{\int_\mu \int_w L(\mu,w)\,P(\mu,w)\,d\mu\,dw}

We will want to compute the normalizing constant \int_\mu \int_w L(\mu,w)\,P(\mu,w)\,d\mu\,dw, which is needed to compare this model with other models. Since this integral is intractable, we will use the midpoint rule to approximate it. The ranges of \mu and w are both infinite, so we apply the following change of variables to \mu and w before applying the midpoint rule: \mu(\mu_t) = \log(\mu_t) - \log(1-\mu_t), \qquad w(w_t) = \log(w_t) - \log(1-w_t)

We then compute the following integral for the normalizing constant: \int_{\mu_t} \int_{w_t} L\big(\mu(\mu_t), w(w_t)\big)\, P\big(\mu(\mu_t), w(w_t)\big)\, \frac{1}{\mu_t(1-\mu_t)}\, \frac{1}{w_t(1-w_t)}\, d\mu_t\, dw_t

Marginal Likelihood

For data y and parameter \theta with likelihood L(\theta) = \prod_{i=1}^n P(y_i\mid\theta) and prior \pi(\theta), the marginal likelihood (evidence) is P(y) = \int L(\theta)\,\pi(\theta)\,d\theta = E_\pi\big[L(\theta)\big] = \int \prod_{i=1}^n P(y_i\mid\theta)\, \pi(\theta)\, d\theta

and the posterior is P(\theta \mid y) = \frac{\prod_{i=1}^n P(y_i\mid\theta)\,\pi(\theta)}{P(y)}

Example: Normal Mean and Log-Variance

Y_1,\dots,Y_n \sim N(\mu,\sigma^2) \mu \sim \pi_\mu(\mu), \qquad \mu \sim N(\mu_0,\sigma_0^2) \sigma^2 \sim \pi_{\sigma^2}(\sigma^2), \qquad w = \log\sigma^2 \sim N(\mu_1,\sigma_1^2)

The marginal likelihood is ML = \iint \left[\prod_{i=1}^n P(y_i \mid \mu,\sigma^2)\right] \pi(\mu)\,\pi(\sigma^2)\; d\mu\, d\sigma^2 = \iint f(\mu,\sigma^2)\, d\mu\, d\sigma^2

Transformation for the Midpoint Rule

To handle the infinite range of \mu, use the logistic transform: \mu_t = \frac{1}{1+e^{-\mu}} \in (0,1), \qquad \mu = \log\left(\frac{\mu_t}{1-\mu_t}\right)

with d\mu = d\left[\log\left(\frac{\mu_t}{1-\mu_t}\right)\right]

To average the (log-)integrand values on the transformed grid, we work on the log scale for numerical stability: \log \sum_{i=1}^{4} e^{\log f(x_i)}

Two-Dimensional Midpoint Rule

For a two-parameter integral, the midpoint rule extends to a grid over (\mu_t, w_t) \in (0,1) \times (0,1): the integrand f(\mu_t, w_t) is evaluated at the midpoint of every grid cell, and the double integral is approximated by summing f over the grid weighted by the cell area.

Marginal Likelihood via the Midpoint Rule

ML = \int L(\theta)\, \pi(\theta)\, d\theta

Difficulty of Numerical Quadrature

We want to compute \int f(x)\,dx over (a,b).

A smooth, wide function is well approximated by a coarse grid. But if f has a sharp, narrow peak relative to the grid spacing, most grid points can miss the peak entirely and the quadrature rule badly underestimates the integral — as illustrated by the tall spike hidden between grid points below.

Difficulty of Numerical Quadrature in High Dimensions

The same problem is far worse in high dimensions. A grid over (\theta_1,\theta_2) must be fine enough to resolve a small concentrated contour region of the integrand, and as the dimension r grows, the fraction of the grid that lands near where the integrand actually has mass shrinks sharply — the required number of grid points grows exponentially with dimension.

Example: Marginal Likelihood via Logistic Transform

Recall the logistic transform used to map an infinite-range parameter \mu to (0,1): \mu_t = \frac{1}{1+e^{-\mu}}, \qquad \mu = \log\left(\frac{\mu_t}{1-\mu_t}\right)

Applying the midpoint rule on the \mu_t grid approximates integrals such as the normalized posterior density \frac{\pi(\theta)\,L(\theta)}{\int \pi(\theta)\,L(\theta)\,d\theta}
