Rejection Sampling

First, review. For \theta \sim f(\theta), we want to estimate I = \int a(\theta)\, f(\theta)\, d\theta by the Monte Carlo method: \hat I = \sum_{i=1}^N a(\theta_i) / N

Overall acceptance rate: \text{Overall Acceptance Rate} = \frac{\int_{-\infty}^{\infty} f(x)\,dx}{\int_{-\infty}^{\infty} g(x)\,dx}

Rejection Sampling 1: choose an envelope function g(x) \ge f(x) for all x.

for (i in 1:n)
  repeat
    Draw x ~ g / integral(g(x) dx)
    r = f(x) / g(x)
    Draw U ~ Unif(0, 1)
    if (U < f(x)/g(x))  x is accepted

Choice of Envelope Function

The tightness of the envelope function determines the efficiency of rejection sampling: a looser envelope g_1(x) wastes more proposals than a tighter one g_2(x) that hugs f(x) more closely.

\text{Overall Acceptance} = \frac{\int f(x)}{\int g(x)}

Theorem

Theorem: Suppose f is a function f(x) \ge 0 with \int f(x)\,dx < \infty. If (X,V) \sim \text{Unif}(\Omega) where \Omega = \{(x,v) \mid 0 < v < f(x)\} then the PDF of X is \frac{f(x)}{\int f(x)\,dx}

Equivalently, if X \sim g(x) and V \mid X \sim \text{Unif}[0, g(x)], then (X,V) \sim \text{Unif}(G) where G = \{(x,v) \mid 0<v<g(x)\}. If we further restrict to (X,V) \in \Omega = \{(x,v) \mid 0<v<f(x)\}, we obtain X with the density above.

Proof of the Theorem

The joint PDF of (X,V) is P(x,v) = \frac{1}{\text{area}(\Omega)}\, I(0<v<f(x)) = \frac{1}{\int_{-\infty}^{\infty} f(x)\,dx} \times I(0<v<f(x))

Then P(x) = \int_{-\infty}^{\infty} P(x,v)\,dv = \int_0^{+\infty} P(x,v)\,dv = \int_0^{f(x)} \frac{1}{\int_{-\infty}^{\infty} f(x)\,dx}\,dv

= \frac{1}{\int_{-\infty}^{\infty} f(x)\,dx} \cdot \int_0^{f(x)} dv = \frac{f(x)}{\int_{-\infty}^{\infty} f(x)\,dx}

Rejection Sampling: Alternative Description

Repeat n times:

  1. Draw X \sim g(x)

  2. Draw V \sim \text{Unif}(0, g(X))

    \left[ V = U \cdot g(X),\quad U \sim \text{Unif}(0,1) \right]

  3. If (V < f(X)) accept X

    V = U \cdot g(X) < f(X) \iff U < \dfrac{f(X)}{g(X)}

    else, go back to 1)

In steps 1) and 2) we draw (X,V) \sim \text{Unif}(G) where G = \{(x,v) \mid v < g(x)\}.

In step 3) we choose (X,V) \in \Omega = \{(x,v) \mid v < f(x)\}.

Rejection Sampling (Alternative Description), Continued

Step 1. Draw (X,V) \sim \text{Unif}(G), G = \{(x,v) \mid 0 < v < g(x)\} — points fill the whole region under g(x).

Step 2. Keep only (X,V) \sim \text{Unif}(\Omega), \Omega = \{(x,v) \mid 0 < v < f(x)\} — i.e., keep only the points that also fall under f(x).

Example 1: Uniform Envelope

Repeat n times. Let f(x) = 2\, I(0 \le x \le \tfrac12), \qquad g(x) = 2\, I(0 \le x \le 1)

Steps:

  1. X \sim \text{Unif}(0,1)
  2. V \sim \text{Unif}(0,1)
  3. r = f(X)/g(X); if (V < r) accept X, otherwise reject and go back to step 1)

In step 3), r = f/g = \begin{cases} 1 & x < \tfrac12 \\ 0 & x > \tfrac12 \end{cases}, so step 3) can be rewritten as:

3*) If (X < \tfrac12) accept X; otherwise go back to step 1).

Overall accept rate = \dfrac{\int_{-\infty}^{\infty} f(x)\,dx}{\int_{-\infty}^{\infty} g(x)\,dx} = \dfrac12.

Example 2

Let \varphi(x) be a density (e.g. the standard normal), and define the truncated density f(x) = \varphi(x)\, I(\mu \le x \le \ell) so that X \sim f(x) = \varphi(x)\, I(\mu \le x \le \ell).

Repeat n times:

  1. Draw X \sim \varphi(x)
  2. If X \in (\mu,\ell), accept X; otherwise go back to 1)

\text{Overall accept rate} = \frac{\int_\mu^\ell f(x)\,dx}{\int_{-\infty}^{\infty} \varphi(x)\,dx} = \int_\mu^\ell f(x)\,dx = P(\mu \le X \le \ell)

Adaptive Rejection Sampling (ARS)

For log-concave f(x) (i.e., \log f(x) is concave), we can build a piecewise-linear majorant of \log f(x) from tangent lines \ell_1(x), \ell_2(x), … on partition intervals I_1, I_2, \dots of the domain, where g(x) = \begin{cases} e^{\ell_1(x)} & x \in I_1 \\ e^{\ell_2(x)} & x \in I_2 \end{cases}, \qquad \log g(x) = \begin{cases} \ell_1(x) & x \in I_1 \\ \ell_2(x) & x \in I_2 \end{cases}

Since g(x) \ge f(x) everywhere, g is a valid envelope for rejection sampling. Moreover F_g(x) = \int_{-\infty}^x g(t)\,dt has closed form, so we can sample from g directly using the inverse CDF: F_g(x) = \int_{-\infty}^x g(t)\,dt = \int_{-\infty}^x e^{a+bt}\,dt

Adaptive Rejection Sampling: Refining the Envelope

As rejected points reveal more information about \log f(x), additional tangent lines are added, refining the piecewise-linear majorant \ell(x) = \log f(x) over successive iterations (superscripts denote the iteration at which each piece \ell_1^{(1)}(x), \ell_2^{(1)}(x), \ell_1^{(2)}(x), \dots was added), giving envelopes g_1(x) = e^{\ell_1^{(1)}(x)}, \qquad g_2(x) = e^{\ell_2^{(1)}(x)}, \ \dots that hug \log f(x) ever more tightly, improving the acceptance rate.

Example: Truncated Normal

Truncated Normal. f(x) = \frac{1}{\sqrt{2\pi}}\, e^{-\frac{x^2}{2}}\, I(u < x < \ell) \log f(x) = -\tfrac12 \log(2\pi) - \frac{x^2}{2}, \quad \text{for } \ell < x < u

A single tangent line at \frac{u+\ell}{2} gives an upper bound \ell(x) \ge \log f(x) on (\ell, u), exponentiating to an envelope g_1(x) = e^{\ell(x)} that stays above f(x) on the whole truncation interval, which can be used to compute/sample P(\ell < Z < u).
